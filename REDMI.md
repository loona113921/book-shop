
# 📚 BookVerse - электронная библиотека

## Описание проекта
Веб-приложение для просмотра, фильтрации и аренды книг. Проект включает два интерфейса: пользовательский и административный.

## Технологии
- **Backend:** Node.js, Express, MongoDB, Mongoose, JWT
- **Frontend:** React, Tailwind CSS, Vite, Lucide Icons
- **Аутентификация:** JWT-токены

## Функциональность

### Пользователь
- ✅ Просмотр книг в виде карточек
- ✅ Сортировка по категории, автору, году, арендованным
- ✅ Аренда книги на 2 недели, месяц или 3 месяца
- ✅ Страница книги с подробным описанием
- ✅ Избранное с синхронизацией в базе данных

### Администратор
- ✅ Добавление, редактирование, удаление книг
- ✅ Управление ценой и статусом (Доступна/Арендована/Недоступна)
- ✅ Автоматические напоминания об окончании аренды

 Анализ выполненной задачи (7 пунктов)
1. Архитектура проекта
Проект построен на современной архитектуре MERN (MongoDB, Express, React, Node.js). Это позволило четко разделить бэкенд (API) и фронтенд (клиентское приложение). Бэкенд работает на порту 500, фронтенд на порту 5173. Такое разделение упрощает масштабирование и поддержку.

2. Разделение интерфейсов
Реализованы два интерфейса:

Пользовательский: Главная страница с книгами, фильтрация по категории и автору, сортировка по году и арендованным книгам, страница книги с арендой.

Административный: Защищен через авторизацию, позволяет управлять книгами (добавление, редактирование, удаление), изменять статус книги, управлять ценой.

3. База данных и модели данных
Создана модель книги с полным набором полей: название, автор, категория, год, описание, обложка, файл, цена, статус, информация об аренде. Также создана модель пользователя с избранным. Индексы в модели ускоряют поиск и сортировку.

4. Система авторизации и избранного
Реализована полноценная система авторизации с JWT-токенами. Пользователи могут регистрироваться и входить. Добавлена система избранного с красными сердечками, синхронизированная с базой данных.

5. Функциональность сортировки и фильтрации
Реализована сортировка по категории, автору, году и арендованным книгам. Фильтрация работает через API-запросы на сервер. Добавлен режим "Избранное" с обновлением URL.

6. Система аренды книг
Разработана система аренды с выбором срока (2 недели, месяц, 3 месяца). При аренде автоматически рассчитывается дата возврата, книга становится недоступной. Реализован механизм возврата книги.

7. Дизайн и пользовательский опыт
Разработан современный темный интерфейс с цветовой гаммой (графитовый фон, желтые/оранжевые акценты). Карточки книг с визуальными индикаторами статуса, адаптивная верстка, парящие эффекты кнопок, закрепленный хедер.

🛠️ Рекомендации по устранению выявленных ошибок
1. Ошибка: Битые ссылки на обложки книг
Проблема: Внешние сервисы могут не работать.
Решение: Использовать локальные файлы обложек или цветные заглушки.

2. Ошибка: Прыжки страницы при фильтрации
Проблема: Контент меняет высоту.
Решение: Добавлена минимальная высота min-h-[350px] и плавные переходы.

3. Ошибка: Длинные названия выходят за карточки
Проблема: Названия книг не помещаются.
Решение: Использован класс truncate с отображением полного названия при наведении.

4. Ошибка: Потеря состояния при обновлении страницы
Проблема: При обновлении выбрасывало на главную.
Решение: Добавлена проверка authLoading и сохранение состояния через URL-параметры.

5. Ошибка: Дублирование кнопки выхода
Проблема: Кнопка выхода была в хедере и в админке.
Решение: Удалена кнопка из админ-панели, оставлена только в хедере.

6. Ошибка: Стрелки в select не видны
Проблема: Кастомные стрелки сливались с фоном.
Решение: Добавлены кастомные SVG-стрелки с отступом pr-10.

7. Ошибка: Алерты при аренде/возврате
Проблема: Алерты не закрывались и раздражали.
Решение: Убраны алерты, страница просто обновляется без уведомлений.
